HOW MACHINES LEARN AND THINK
CLASS 1
Our Very First Machine Mind
Introduction

A NEURON needs at least one WEIGHT to do anything useful.

To learn from data, a mind also needs a PARAMETER UPDATE RULE.

Mind

We're going to build a machine mind that can multiply any number by 5.0.

In this scenario, the INPUT represents the number being multiplied, and the OUTPUT represents the result of the multiplication.

Let's call this mind the Multiplier-by-Five.

It will have a single PARAMETER: WEIGHT.

The mind will be a simple formula like this:

OUTPUT = INPUT × WEIGHT

We need to find the correct PARAMETER: WEIGHT.

Initial PARAMETER

Suppose we don't yet know what the PARAMETER should be, so let's start by setting it to zero:

WEIGHT = 0.0

At first, the mind will generate nonsense, since with any INPUT the OUTPUT is zero.

Dataset

We have this training DATASET consisting of two EXAMPLES:

INPUT TARGET
EXAMPLE 1 0.6 3.0
EXAMPLE 2 1.0 5.0

EXAMPLE 1 means when the INPUT is 0.6, the OUTPUT must be 3.0.
EXAMPLE 2 means when the INPUT is 1.0, the OUTPUT must be 5.0.

During TRAINING, in each LESSON, the mind updates the PARAMETER so that the OUTPUT gets closer to the TARGET.

Update Rule

The mind updates the PARAMETER using this UPDATE RULE:

SIMPLEST UPDATE RULE for PARAMETER
PARAMETER_update = ERROR
PARAMETER = PARAMETER + PARAMETER_update

Because the mind has just one PARAMETER — WEIGHT — we obtain:

SIMPLEST UPDATE RULE for WEIGHT
WEIGHT_update = ERROR
WEIGHT = WEIGHT + WEIGHT_update

Don't worry — each step is simple. Just follow the calculations below.

Training
LESSON 1
WEIGHT = 0.0

EXAMPLE 1:

INPUT = 0.6
TARGET = 3.0
Forward Pass — Inference
PRODUCT = INPUT × WEIGHT = 0.6 × 0.0 = 0.0
OUTPUT = PRODUCT = 0.0
Error
ERROR = TARGET − OUTPUT = 3.0 − 0.0 = 3.0

The ERROR tells us how far the OUTPUT is from the TARGET.

Backward Pass — Backpropagation

Imagine the mind asking itself:

"How should I change my WEIGHT so the OUTPUT gets closer to the TARGET?"

The ERROR provides the answer:

"Your OUTPUT is 3.0 below the TARGET, so increase the WEIGHT by 3.0."

And that's exactly what the UPDATE RULE tells us to do:

SIMPLEST UPDATE RULE for WEIGHT
WEIGHT_update = ERROR
WEIGHT = WEIGHT + WEIGHT_update
WEIGHT = 0.0
ERROR = 3.0
WEIGHT_update = ERROR = 3.0
WEIGHT = WEIGHT + WEIGHT_update = 0.0 + 3.0 = 3.0

So the WEIGHT becomes 3.0.
WEIGHT = 3.0
What just happened?

The mind has just improved itself.

Now, if it receives the same INPUT of 0.60, the OUTPUT becomes 1.8 — which is closer to the TARGET (3.0) than the previous OUTPUT (0.0) was.

The ERROR becomes smaller:

ERROR = 1.2


LESSON 1 ends here.

LESSON 2
WEIGHT = 3.0

EXAMPLE 2:

INPUT = 1.0
TARGET = 5.0
Forward Pass — Inference
PRODUCT = INPUT × WEIGHT = 1.0 × 3.0 = 3.0
OUTPUT = PRODUCT = 3.0
Error
ERROR = TARGET − OUTPUT = 5.0 − 3.0 = 2.0
Backward Pass — Backpropagation

Imagine the mind asking itself again:

"How should I change my WEIGHT so the OUTPUT gets closer to the TARGET?"

The ERROR provides the answer:

"Your OUTPUT is 2.0 below the TARGET, so increase the WEIGHT by 2.0."

And that's exactly what the UPDATE RULE tells us to do:

SIMPLEST UPDATE RULE for WEIGHT
WEIGHT_update = ERROR
WEIGHT = WEIGHT + WEIGHT_update
WEIGHT = 3.0
ERROR = 2.0
WEIGHT_update = ERROR = 2.0
WEIGHT = WEIGHT + WEIGHT_update = 3.0 + 2.0 = 5.0

So the WEIGHT becomes 5.0.
WEIGHT = 5.0
What just happened?

The mind has just improved itself again.

Now, if it receives the same INPUT of 1.0, the OUTPUT becomes 5.0 — which is closer to the TARGET (5.0) than the previous OUTPUT (3.0) was.

Wait — it's not just closer. It's exact!

The OUTPUT is now 5.0 — exactly the same as the TARGET.

The ERROR becomes zero:

ERROR = 0.0


LESSON 2 ends here.

✓   DONE   ✓
Testing

To test the mind, we give it a new EXAMPLE it has never seen before.

WEIGHT = 5.0

EXAMPLE for TESTING:

INPUT = 10.0
TARGET = 50.0
Forward Pass
PRODUCT = INPUT × WEIGHT = 10.0 × 5.0 = 50.0
OUTPUT = PRODUCT = 50.0
Error
ERROR = TARGET − OUTPUT = 50.0 − 50.0 = 0.0

Since ERROR = 0.0, this mind works perfectly!

It has learned the rule: multiply any number by 5.0.

The Multiplier By Five can now solve problems it has never encountered before.

The mind is now just this formula:

OUTPUT = INPUT × 5.0
