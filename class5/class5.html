HOW MACHINES LEARN AND THINK
CLASS 4
BIAS
Introduction

Here, we add BIAS to the NEURON. So the brain will have two PARAMETERS: WEIGHT and BIAS.

During TRAINING, in each LESSON, these PARAMETERS will compete over which gets updated more. The PARAMETER that gets a larger product of ERROR and INFLUENCE — i.e., ERROR × PARAMETER_OUTPUT_influence — receives a larger update.

To see this competition more clearly, let's set PACE to 1.0:

PACE = 1.0
Brain

We're going to build a machine brain that can convert Celsius temperatures to Fahrenheit temperatures.

In this scenario, the INPUT represents Celsius and the OUTPUT represents Fahrenheit.

Let's call this brain the Converter-°C-to-°F.

As previously noted, it will have two PARAMETERS: WEIGHT and BIAS.

The brain will be just a formula like this:

OUTPUT = INPUT × WEIGHT + BIAS
Initial PARAMETERS

Suppose we don't yet know what these PARAMETERS should be, so let's start by setting them to zero:

WEIGHT = 0.0
BIAS = 0.0

At first, the brain will generate nonsense, since with any INPUT the OUTPUT is zero.

Dataset

We have this training DATASET consisting of two EXAMPLES:

# INPUT TARGET
EXAMPLE 1 0.0 32.0
EXAMPLE 2 1.0 33.8

EXAMPLE 1 means when the INPUT is 0.0, the OUTPUT must be 32.0, because 0.0°C equals 32.0°F.

EXAMPLE 2 means when the INPUT is 1.0, the OUTPUT must be 33.8, because 1.0°C equals 33.8°F.

During TRAINING, in each LESSON, the brain updates each PARAMETER so that the OUTPUT gets closer to the TARGET.

Update Rule

The brain updates each PARAMETER using the FUNDAMENTAL UPDATE RULE:

FUNDAMENTAL UPDATE RULE for PARAMETER
PARAMETER_update = ERROR × PARAMETER_OUTPUT_influence × PACE
PARAMETER = PARAMETER + PARAMETER_update

Because the brain has two PARAMETERS — WEIGHT and BIAS — we obtain these two update rules:

FUNDAMENTAL UPDATE RULE for WEIGHT
WEIGHT_update = ERROR × WEIGHT_OUTPUT_influence × PACE
WEIGHT = WEIGHT + WEIGHT_update
FUNDAMENTAL UPDATE RULE for BIAS
BIAS_update = ERROR × BIAS_OUTPUT_influence × PACE
BIAS = BIAS + BIAS_update

Don't worry — each step is simple. Just follow the calculations below.

CHAIN of INFLUENCES
WEIGHT_OUTPUT_influence = WEIGHT_PRODUCT_influence × PRODUCT_SUM_influence × SUM_OUTPUT_influence
What is WEIGHT_PRODUCT_influence here?
Our formula is: PRODUCT = INPUT × WEIGHT
The number that multiplies the WEIGHT is INPUT.
Therefore: WEIGHT_PRODUCT_influence = INPUT
WEIGHT_PRODUCT_influence = INPUT = 0.0
What is PRODUCT_SUM_influence here?
The formula is: SUM = PRODUCT + BIAS
We can re-write it this way: SUM = 1.0 × PRODUCT + BIAS
The number that multiplies the PRODUCT is 1.0.
Therefore: PRODUCT_SUM_influence = 1.0
PRODUCT_SUM_influence = 1.0
What is SUM_OUTPUT_influence here?
Our formula is: OUTPUT = SUM
We can re-write it this way: OUTPUT = 1.0 × SUM
The number that multiplies the SUM is 1.0.
Therefore: SUM_OUTPUT_influence = 1.0
SUM_OUTPUT_influence = 1.0

WEIGHT_OUTPUT_influence = WEIGHT_PRODUCT_influence × PRODUCT_SUM_influence × SUM_OUTPUT_influence = 0.0 × 1.0 × 1.0 = 0.0

WEIGHT_update = ERROR × WEIGHT_OUTPUT_influence × PACE = 32.0 × 0.0 × 1.0 = 0.0

WEIGHT = WEIGHT + WEIGHT_update = 0.0 + 0.0 = 0.0
